# Introduction to JavaScript

JavaScript is a lightweight, high-level programming language primarily used to add interactivity to web pages. It runs in browsers and can also run on servers through Node.js.

## Why JavaScript?
- Builds interactive user interfaces
- Handles form validation and form submission
- Creates animations and dynamic content
- Works with APIs and backend services
- Runs on both frontend and backend

## JavaScript in the Browser
Browsers provide a JavaScript engine that executes code. JavaScript can:
- change HTML content
- modify CSS styles
- respond to user events
- fetch data from servers asynchronously

## JavaScript in Node.js
Node.js allows JavaScript to run outside the browser, which enables:
- server-side development
- command-line tools
- automation scripts
- APIs and backend services

## Basic Syntax
```javascript
console.log("Hello, JavaScript!");
```

This prints a message to the console.

## Statements and Semicolons
JavaScript statements are instructions. A semicolon is optional in many cases but commonly used:

```javascript
const message = "Welcome";
console.log(message);
```

## Comments
```javascript
// Single-line comment

/*
  Multi-line comment
*/
```

## Execution Flow
JavaScript reads code from top to bottom, unless control structures or functions change the flow.

## Best Practice
Write clean, readable code with meaningful variable names and consistent formatting.

## Example
```javascript
let userName = "Ash";
console.log("Hello, " + userName);
```

## Summary
JavaScript is the language of the web. It helps create dynamic, interactive, and responsive experiences for users.
